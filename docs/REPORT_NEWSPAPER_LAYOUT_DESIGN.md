# PhotoSense AI 分析报告：报纸式排版设计规范

版本：1.1  
日期：2026-09-11  
适用范围：分析报告页面的屏幕排版；不改变报告字段、评分、文案、照片、来源标识和 01–05 章节顺序。

## 1. 参考图的共同设计要素

### 参考 A：传统头版

- 超大报头和次一级头条形成清楚的两级标题。
- 日期、期号和来源位于一条紧凑的信息带内。
- 主图与正文并列，图片不是独立卡片，而是文章证据的一部分。
- 横线只用于报头、信息带和文章边界，不给每段文字套框。

### 参考 B：文化专题版

- 头条横跨整版，先确定主题，再进入图文内容。
- 主图约占内容宽度的三分之二，右侧三分之一承载次要故事或补充信息。
- 图片下方正文使用等宽栏网，栏距稳定，短段不会被拉成整版宽度。
- 大图、侧栏和正文共享同一对齐线，页面因此紧凑而不拥挤。

### 参考 C：字体与版式说明版

- 衬线字体承担报头、头条和章节名；无衬线字体承担说明、标签和正文。
- 大标题、章节标题、正文、图注和标签形成固定字号阶梯。
- 多个信息模块通过栏网、留白和少量横线组成连续页面，而不是卡片墙。
- 红色只用于栏目名、序号和重点，不成为大面积背景。

## 2. 转译到 PhotoSense 的原则

PhotoSense 不复制报纸的品牌、浅色纸张、英文报头或仿旧纹理，只采用其信息组织方式：

1. 报告目录等同于报纸的“期号信息带”，从左侧固定栏改为横向五栏目录，释放正文宽度。
2. 评审结论等同于头条，必须成为首屏最大的文字焦点。
3. 用户照片等同于头版主图，和评分、主要问题、本张先改共同组成一个版面，不单独漂浮。
4. 五维评分、观察、后期建议和评价依据按二至四栏排版，避免狭窄五栏和整段超长行。
5. 章节之间依靠 88–136 px 留白区分；横线只出现在目录、图注和确有结构作用的跨栏转换处。
6. 橙红仅标记栏目名、分数、最高/最低状态和步骤编号。
7. 每个章节只保留一个概括性标题；不叠加同义眉题、主标题和内部标题。

报告目录和正文标题统一为：`01 评审结论`、`02 五维诊断`、`03 后期建议`、`04 下次拍摄`、`05 评价基准`。

## 3. 页面栅格

### 桌面端：大于 1180 px

- 页面正文最大宽度：1320 px。
- 外边距：32–48 px。
- 基础栅格：12 栏。
- 栏距：24–32 px；图文大分区栏距可扩大至 40–56 px。
- 正文行宽：每栏约 20–34 个中文字符。

### 平板端：761–1180 px

- 页面使用 6 栏栅格。
- 报告目录保持横向五栏；空间不足时允许横向滚动，但不得截断栏目文字。
- 头版、后期图文区改为单栏；观察和评价依据保留两栏。

### 手机端：不大于 760 px

- 页面使用单栏。
- 横向目录改为可滚动索引条，每个入口至少 44 px 高。
- 阅读顺序固定为：头条 → 一句话结论 → 主要问题 → 本张先改 → 主图 → 综合评分。
- 所有二、三、四栏结构折叠为单栏，不使用浮动文字环绕。

## 4. 报告章节模板

### 01 评审结论：头版模板

- 第一行：评审结论、头条和一句话结论横跨版面。
- 竖幅照片：第二行主图占 8 栏、评分占 4 栏；两者按各自模块的垂直中心对齐。
- 横幅照片：第二行先用整行展示评分；左半区为综合分数和雷达图，右半区为五维分数；第三行再展示整幅照片。
- 评分模块只保留综合分数、雷达图和五维分数，不重复介质、题材与水平说明。
- 主要问题和本张先改属于评审结论，和一句话结论组成独立阅读组，不挤入评分侧栏。
- 图片元数据作为图注贴近图片下缘。
- 竖幅主图与评分模块共享一条水平中心线；横幅主图单独占据完整内容宽度。

### 画面观察：专题摘要模板

- 章节标题横跨整行。
- 值得保留、最优先问题、画面区域、本张调整组成 2 × 2 栏网。
- 裁剪参考横跨整行，比例作为短数据列，说明作为长正文列。

### 02 五维诊断：多栏正文模板

- 桌面使用三栏，平板使用两栏，手机使用一栏。
- 每个诊断项保持“标题和分数 → 评分依据 → 结论 → 建议”的内部顺序。
- 不使用独立卡片底色；仅用列对齐、段前距和必要的短横线。

### 03 后期建议：主图加侧栏模板

- 效果预览占 7 栏，三条后期建议占右侧 5 栏并纵向排列。
- 预览说明作为图片图注，不另建大面板。
- 平板和手机改为预览在前、建议在后。

### 04 下次拍摄：三栏行动模板

- 摘要横跨整行。
- 三条行动在桌面端按三栏排列；序号、动作和对象对齐。
- 手机端按 01–03 顺序纵向排列。

### 05 评价基准：四栏资料模板

- 本次评价基准与介质/水平/题材信息共用一条信息带。
- 影像介质、评价水平、摄影题材、评分侧重使用四栏。
- 辅助文字使用暖白次级色，不能降低到接近背景的灰色。

## 5. 文字环绕图片规则

报纸常用文字环绕，但 PhotoSense 的报告正文包含技术建议与行动步骤，强制环绕会破坏扫描顺序。因此：

- 桌面端优先使用“主图 + 结构化侧栏”，取得和文字环绕相同的空间利用效果。
- 只有连续叙述超过 180 个中文字符、且没有列表或评分时，才允许首图右浮动并由正文环绕。
- 760 px 以下禁止浮动环绕，避免过窄文字列和阅读顺序混乱。
- 当前报告无需强制文字环绕；头版侧栏和后期预览侧栏更适合现有内容。

## 6. 字体与层级

- 头条：`--em-serif`，48–92 px，行高 0.98–1.06。
- 五个章节主标题：`--em-serif`，42–74 px，行高 1.04–1.12；前一章节结束至新章节标题保留 88–136 px。
- 章节内小标题：`--em-serif` 或 `--em-sans`，20–32 px，行高 1.15–1.3。
- 正文：`--em-sans`，16–18 px，行高 1.7–1.8。
- 标签和图注：`--em-sans`，14–15 px，行高 1.45–1.6。
- 分数、日期、文件参数：`--em-mono`。
- 全页不得新增第四种字体。

## 7. 间距层级

- 一个阅读单元内部遵守“标题紧随正文”：标签或小标题与对应正文间距为 8–12 px。
- 同级阅读单元之间必须明显更宽：双栏摘要、观察条目、诊断字段和评价字段之间为 24–72 px，随栅格密度调整。
- 章节标题到本章主体内容为 36–72 px，不能小于同一单元内部间距。
- 相邻大章节之间为 88–136 px；手机端至少 72 px。
- 判断标准：先能看出“哪一段文字属于哪个小标题”，再能看出“哪几个小单元共同组成一个章节”。

## 8. 验收标准

- 报告的全部原有内容、字段和 01–05 章节 ID/顺序保持不变。
- 目录名称与章节语义一致；每个章节标题区只出现一个标题。
- 1440 px 下不再出现固定左目录造成的窄正文；主图与侧栏同时进入首屏主体。
- 竖幅照片与评分模块垂直中心对齐；横幅照片使用“整行评分在上、整幅照片在下”的顺序。
- 综合评分中不出现“基于介质、题材与评价水平的学习参考”说明句。
- 每个小标题与自己的正文间距小于它和下一同级单元的间距；五个章节标题均具有清楚的字号和段前留白。
- 1440 px 下五维诊断为三栏、后期预览为 7/5 图文结构、评价依据为四栏。
- 760 px 与 390 px 无横向溢出、遮挡和小于 44 px 的持久导航入口。
- 用户照片无滤镜、无变色、无替代图。
- 运行 `npm.cmd run check`，并完成报告总览、画面观察、五维诊断、后期建议和评价依据的视觉截图验证。
